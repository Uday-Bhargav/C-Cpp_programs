# Number Guessing Game in C

A simple **Number Guessing Game** written in C.

## Concepts used
- Input/Output (`scanf`, `printf`)
- Loops (`do-while`)
- Conditional statements (`if-else`)
- Random number generation (`rand`, `srand`)

## How to Run
1. Compile using a C compiler: `gcc NumberGuessingGame.c -o game.exe`
2. Run the executable: `game.exe`
3. Guess the number following prompts

## Sample Output
Guess the number : 50
Guess a higher number
Guess the number : 75
Guess a lower number
Guess the number : 62
Congrats! You guessed correctly in 3 tries!
